# Roadmap

## M0 + M1 已完成：能玩

- 单人题库。
- 双答题模式：手动输入 / 候选字格子。
- 游客进度保存在 `localStorage`。
- 答对、答错、提示、下一题。
- Go API、Vue 玩家端、独立 Vue 管理后台。
- PostgreSQL 题库和投稿审核。

## M1.5 基线补齐：好用、好开发

- 题目选择页，避免首页多个入口都直接进入 `/game`。
- 设置页：答题偏好、音效/震动、清空本地进度。
- 游戏页和投稿页错误态、空态、重试。
- 解释接口路由补齐。
- 管理后台退出登录和 token 失效提示。
- README、API 文档、环境变量示例、CI 基线。

## M2 有账号

- 玩家注册登录。
- JWT 或等价 token 机制。
- 游客进度迁移到账号。
- 跨设备进度同步。
- 成就弹窗和个人中心。

## M3 能创作

- 出题编辑器。
- 图片上传，接入 MinIO。
- 创意工坊浏览。
- 我的投稿、投稿状态追踪。
- 审核详情页、批量审核、下架/恢复。

## M4 能联机

- WebSocket 房间。
- 创建、加入、准备、开始、结算。
- 经典多人模式。
- Redis 房间状态和在线状态。
- 实时排行榜和断线重连。

## M5 能上线运营

- 生产环境配置和部署脚本。
- 数据库迁移工具。
- 结构化日志、request id、监控。
- CORS 白名单、限流、安全加固。
- Postgres 和 MinIO 备份恢复。
- 移动端适配和性能优化。
